# Clythix JSON to TypeScript Converter

A lightning-fast, minimalist web utility designed for developers to convert raw JSON payloads into clean, production-ready TypeScript interfaces instantly.

## Quick Start

Just open `index.html` in any modern web browser to use the tool locally!

## Tech Stack

* HTML5 / CSS3 (Modern Light Theme)
* Vanilla JavaScript (Zero bloated libraries)

## Features

* Instant JSON parsing and error detection
* Automatic type inference for nested objects and arrays
* One-click copy button for quick code export
